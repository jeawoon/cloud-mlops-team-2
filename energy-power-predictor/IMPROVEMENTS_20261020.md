## CSV

사용자가 Wh / kWh / 10분 평균 W 중 단위를 명시합니다. 평균 W는 6으로 나눠 Wh로 변환합니다. 시간 역순·중복·누락·미래·비정상 전력값을 거절합니다. 예제 파일은 합성값이지 실측 데이터가 아닙니다. 원본 업로드 파일을 디스크에 저장하지 않습니다. 다만 사용자가 기록 저장에 동의하면 변환된 입력값이 기록에 포함됩니다.

냉장고의 선택적 24시간 모델에는 연속 144개 완료 구간이 필요합니다. 최근 6개만으로 동작하는 기존 모델은 그대로 유지합니다.

## 모델 비교

동일한 REFIT House2 테스트 12,380건 비교입니다. 후보 선택은 검증 구간 R²로 수행했습니다.

| 가전 | 기존 고정 모델 R² | 선택한 24시간 후보 R² | 조치 |
|---|---:|---:|---|
| 냉장고 | 0.786665 | 0.811880 | 선택 기능으로 제공 |
| 식기세척기 | 0.923067 | 0.859191 | 성능 저하로 비활성화 |

기존 전체 14,933건 성적(냉장고 0.7897, 식기세척기 0.9303)과 표본이 다릅니다. 0.85 달성 또는 새로운 독립 성능 검증을 주장하지 않습니다. 후보·분할·오차 범위·모델 SHA는 `models/calibration_metrics.json`에 기록했습니다. 기존 세탁 모델과 다음 10분 기본 모델 파일은 변경하지 않았습니다.

재현: 원본 REFIT/LARCO 파일을 준비한 후 `python prepare_calibration.py --help`의 경로 옵션을 확인하세요. 테스트 정답을 추론 입력에 넣지 않습니다. 오차 범위 보정에는 기존 테스트 전반부를 사용하고 후반부에서 포함률을 측정했으므로 별도 독립 미래 데이터 확인이 필요합니다.

## 요금·개인정보·운영

- 고정 단가 기본 200원은 예시입니다. 누진 방식은 별도 동의 후 참고 계산이며 화면의 표 버전·기후환경·연료비 조정 가정을 확인해야 합니다. 개별 고정 단가 요금 합계와 누진 차액은 다를 수 있습니다.
- 기록은 기본 `work/user_history.sqlite3`에 저장되며 파일 권한은 0600입니다. 환경변수 `ENERGY_HISTORY_DB`로 위치를 지정할 수 있습니다. 디스크 암호화/백업은 운영자가 별도 설정해야 합니다.
- 접근 키 원문 대신 해시를 저장합니다. 키를 아는 사람은 기록에 접근할 수 있으므로 공개하거나 Git에 올리지 마세요. 원본 CSV·IP·계정 정보를 자동 저장하지 않습니다. 최근 100개를 화면에 보여주며 소유자별 최대 1,000개를 허용합니다.
- API는 루프백에만 바인딩합니다. 선택적 `PREDICTION_API_TOKEN`은 서버 환경변수로 주고 Streamlit에도 같은 값을 설정합니다. 브라우저에 노출하지 마세요. 제한은 API 연결 IP 기준이므로 Streamlit을 경유한 사용자는 한도를 공유할 수 있습니다.
- 운영 방법은 `deploy/README.md`를 참고하세요. Docker가 없어 빌드/컨테이너 실행은 검증하지 못했습니다. 실제 도메인·DNS·80/443·고정 IP·HTTPS는 설정 전입니다. 기존 AWS 서버를 자동으로 변경하지 않았습니다.
