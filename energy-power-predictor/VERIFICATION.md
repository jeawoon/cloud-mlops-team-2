## 모델 성능 재확인

새 학습·모델 교체 없이 REFIT 원본 체크섬과 기존 전처리/시간순 테스트 경계를 이용해 모델 출력을 다시 계산했습니다.

| 대상 | 테스트 수 | R² | MAE | 범위 |
| --- | ---: | ---: | ---: | --- |
| 세탁기 | 131회 | 0.8835 | 98.63Wh | 저장된 LARCO 평가 기록, 코스 1회 전체 |
| 냉장·냉동고 | 14,933건 | 0.789664 | 1.732407Wh | REFIT 재계산, 다음 10분 |
| 식기세척기 | 14,933건 | 0.930335 | 2.403511Wh | REFIT 재계산, 다음 10분 |

LARCO 이번 실측 예제는 기존 테스트 ID에서 가져온 2회입니다. 세탁 전체 131회 지표를 이번에 새로 독립 평가한 것은 아닙니다. 기존 테스트 기간을 반복 확인하므로 새 미래 데이터로 검증한 결과가 아닙니다. R²는 적중률(%)이 아니며 서로 다른 예측 대상의 지표를 합치지 않습니다. 계획 산식 전체의 R²는 미검증입니다.

## 고정된 검증 예제

원본 데이터는 수정하지 않았으며 다운로드도 다시 하지 않았습니다. 정답은 예제 표시/오차 계산에만 사용합니다. 모델에 전달하는 입력 JSON에는 실제 미래 소비량이나 고정된 예상 출력이 없습니다.

예제 선택 규칙은 예측 오차를 보기 전에 정한 규칙입니다. 세탁은 테스트 ID 순서에서 제품별 첫 API 지원 예제(고장 제품 제외), 냉장고/식기세척기는 테스트 첫 유효 구간과 정답 1Wh 미만인 첫 구간을 사용합니다. 소수 예제를 대표 성능이나 R²의 근거로 삼지 않습니다.

| 예제 ID | 정답 Wh | 예측 Wh | 절대오차 Wh | 의미 |
| --- | ---: | ---: | ---: | --- |
| formula-tv | 200.000 | 200.000 | 0.000 | 100W TV, 60분, 2대의 독립 산식; 실측 아님 |
| laundry-1 | 125.198 | 100.287 | 24.911 | 세탁코스 전체 실측 |
| laundry-2 | 488.739 | 544.916 | 56.177 | 다른 세탁 제품의 코스 전체 실측 |
| fridge-first | 14.918 | 14.538 | 0.379 | 냉장고 다음 10분 실측 |
| fridge-low | 0.167 | 0.284 | 0.117 | 냉장고 낮은 사용량 구간 |
| dishwasher-first | 166.504 | 106.481 | 60.022 | 식기세척기 다음 10분 실측 |
| dishwasher-low | 0.218 | 3.238 | 3.021 | 식기세척기 낮은 사용량 구간 |

식기세척기 첫 예제의 큰 오차도 그대로 표시합니다. ‘출력 재현 일치’는 고정된 모델이 같은 입력에 같은 예측을 했다는 뜻이며 실측 정답 적중 판정이 아닙니다. 200원/kWh는 산식 예시 단가이고 실제 한전 청구액이 아닙니다.

출처·레코드·선택 규칙·예측 시점·실제값·입력·모델 SHA-256은 `models/verification_cases.json`에 기록했습니다. 모델이 바뀌면 체크섬 검사가 이전 예제 사용을 차단합니다. 이 예제는 재학습에 사용하지 않았습니다.

브라우저에서도 산식 예제 200Wh·40원·오차 0과 세탁 예제 125.198Wh/100.287Wh/오차 24.911Wh를 확인했습니다. 브라우저 error 로그는 발견되지 않았습니다. 예측 API·웹 health는 정상입니다. 자동화한 브라우저 확인을 ‘사람의 확인 완료’로 대체하지 않습니다.

## 직접 확인하는 방법

1. 로컬 API와 웹을 README대로 실행합니다.
2. 기본 가전 화면에서 TV, 100W, 60분, 2대를 입력해 0.2kWh·40원(200원/kWh 단가)을 확인합니다.
3. 화면 아래 **검증용 예제: 실측 정답과 예측 비교**를 펼칩니다.
4. 예제를 선택하고 **검증 예제 예측 실행**을 누릅니다. 입력 JSON, 범위, 출처, 실측값·예측값·절대오차를 확인합니다.
5. 산식/실측, 코스 전체/다음 10분, 에너지 환산 요금/실제 청구액의 차이를 확인합니다.
6. 실제 확인을 마친 사람만 확인 체크를 선택하고 결과 JSON을 내려받습니다. 체크 결과는 해당 브라우저 상태일 뿐 서버 저장·신원 확인·팀원 승인 기록은 아닙니다.
