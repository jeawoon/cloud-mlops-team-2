### 2. 세 가지 계산 방식 분리

#### 시간·소비전력 입력 — 9종 가전

사용 시간·가동 W·가동 비율·대수·시작 지연을 입력합니다. 가전별 기본 W와 대기 W는 보존한 REFIT 실측 통계에서 가져오며, 사용자는 가동 W를 자신의 제품 값으로 바꿀 수 있습니다.

```text
평균 W = 가동 W × 가동 비율 + 대기 W × (1 − 가동 비율)
예상 Wh = 평균 W × 사용 시간(분) / 60 × 대수
예상 kWh = 예상 Wh / 1000
예상 추가요금 = 예상 kWh × 입력 단가(원/kWh)
```

- 이 방식은 사용자가 가정한 조건을 계산하는 방식입니다. 새로운 머신러닝 모델의 실측 예측 성능이 아닙니다.
- 냉장고 가동 비율 기본 50% 등은 예시 가정이며 개인 가전의 실제 가동률을 학습한 값이 아닙니다.
- 사용 시간 0분이면 사용량 0입니다. 여러 대는 같은 소비전력·운전 조건이라고 가정합니다.
- 이 계획 계산과 선택 계획 전체의 R²는 미검증이며 API의 `plan_r2`는 `null`입니다.

#### 세탁코스 학습 모델 — 세탁기

- 입력: 데이터에 포함된 제품 모델, 프로그램, 설정 온도, 목표 세탁물 무게, 시작 전 주변 온도.
- 출력: 코스 1회 완료까지 예상 에너지와 예상 소요시간.
- 임의로 지정한 10분 사용량이나 중간에 끄는 시나리오를 예측하는 모델이 아닙니다.
- 데이터의 제품별 프로그램·설정 조합과 무게/온도 범위로 입력을 제한합니다. 고장 상태 실험 제품은 화면에 경고합니다.

#### 최근 기록 학습 모델 — 냉장·냉동고 / 식기세척기

- 입력: 해당 가전의 최근 완료된 10분 사용량 6개(최신순), 마지막 구간 종료 시각·요일.
- 출력: 해당 가전의 현재부터 다음 10분 에너지와 입력 단가 기준 추가요금.
- 집 전체 사용량이나 다른 가전의 기록을 입력하는 모델이 아닙니다.
- 이 모드는 미래 시작 지연을 허용하지 않습니다. 미래 시작 계획은 시간·소비전력 입력 방식을 사용합니다.
- 기본 기록 값은 데모입니다. 실제 기록 없이 해당 가정의 정확도를 보장하지 않습니다.

세탁코스 전체와 냉장고 다음 10분처럼 서로 다른 범위를 섞은 합계는 선택 계획들의 에너지 합계입니다. 같은 10분 구간이나 집 전체 사용량을 의미하지 않습니다.

### 3. 학습 데이터·모델·평가 방식

#### LARCO 세탁코스 모델

- 출처: [LARCO 공식 데이터](https://zenodo.org/records/18657997), 저장된 출처 정보의 라이선스 `CC-BY-4.0`.
- 실험실 세탁기 유효 코스 642회 사용. 제품별 획득 시각순으로 학습 383회 / 검증 128회 / 테스트 131회 분리.
- 개별 코스가 학습·검증·테스트에 겹치지 않는지 검사하고 원본 SHA-256을 확인합니다.
- 입력에서 실제 종료시간·실제 에너지·소비전력 통계·작동 후 무게/온도·KPI를 제외합니다.
- 설정 온도와 주변 온도의 차이, 목표 무게를 이용한 가열 부하 대리 피처를 추가합니다.
- 에너지와 소요시간 각각 Ridge, Gradient Boosting(깊이 2/3), Extra Trees를 검증 구간에서 비교합니다. 두 목표 모두 Ridge가 선택됐으며 학습+검증 구간으로 재학습 후 테스트합니다.
- 다운로드 스크립트는 버전이 고정된 압축 파일에서 필요한 요약 CSV 부분만 요청하고 크기·CRC·내용을 검사합니다. 원본 요약 약 1.3MB는 로컬 데이터 폴더에 보존하며 Git에는 넣지 않습니다.
- 결과 파일: [larco_cycle_metrics.json](models/larco_cycle_metrics.json), 모델 파일: `models/larco_cycle_model.joblib`.

#### REFIT 냉장·냉동고 / 식기세척기 모델

- 출처: [REFIT 공식 데이터](https://zenodo.org/records/5063428), 저장된 출처 정보의 라이선스 `CC-BY-4.0`.
- House2의 Appliance1(냉장·냉동고), Appliance3(식기세척기)를 별도 예측합니다. 집 전체 모델을 추가 학습한 것이 아닙니다.
- 원본 MD5 확인, 센서 문제 표시 행 제외, 0~4,000W 밖의 값 제외, 유효 측정 60개 미만인 10분 구간 제외.
- 10분 구간의 라벨은 구간 종료 시각입니다. 예측 시점에 완료된 기록만 입력합니다.
- 피처 12개: 최근 6개 사용량, 직전 변화량, 최근 평균·표준편차, 시각 sin/cos, 주말 여부. `rv1`, `rv2`, 미래 측정값, 집 전체·다른 가전 채널은 사용하지 않습니다.
- 원본 시간축 앞 60% / 다음 20% / 뒤 20%로 학습·검증·테스트를 나누고 미래 정답이 분할 경계를 넘는 행을 제외합니다.
- 가전별 유효 학습 29,235건 / 검증 15,885건 / 테스트 14,933건. 모델 선택 후 학습+검증 구간으로 재학습합니다.
- HistGradientBoosting의 최대 리프 7/15/31과 Extra Trees를 검증 R²로 비교합니다. 냉장고는 `hist_15`, 식기세척기는 `extra_trees`가 선택됐습니다.
- 테스트 입력 구간: 2015-01-24 20:40:00 ~ 2015-05-28 07:50:00(원본 기록 시각 기준). 이전에 확인한 기간이므로 새로운 미래 구간에서 독립 검증이 필요합니다.
- 결과 파일: [device_forecast_metrics.json](models/device_forecast_metrics.json), 모델 파일: `models/device_forecast_model.joblib`.

### 4. 저장된 실측 테스트 지표

| 대상 | 예측 목표 | 테스트 수 | R² | MAE | RMSE |
| --- | --- | ---: | ---: | ---: | ---: |
| 세탁기 | 코스 1회 전체 에너지 | 131회 | 0.8835 | 98.63Wh | 126.92Wh |
| 냉장·냉동고 | 다음 10분 에너지 | 14,933건 | 0.7897 | 1.73Wh | 3.02Wh |
| 식기세척기 | 다음 10분 에너지 | 14,933건 | 0.9303 | 2.40Wh | 13.52Wh |

세탁코스 소요시간 모델은 같은 131회 테스트에서 R² 0.8955, MAE 13.67분입니다.

REFIT의 동일 테스트 샘플에서 직전 값 유지 기준선과 비교한 결과:

| 대상 | 직전 값 유지 R² → 선택 모델 R² | 직전 값 유지 MAE → 선택 모델 MAE |
| --- | --- | --- |
| 냉장·냉동고 | 0.3445 → 0.7897 | 2.91Wh → 1.73Wh |
| 식기세척기 | -0.1978 → 0.9303 | 12.88Wh → 2.40Wh |

이 표는 각 가전의 같은 정답·같은 테스트 구간에서만 비교합니다. 이전 온습도·집 전체 모델과 새 모델은 정답 대상과 기간이 달라 단순한 R² 상승 비교를 하지 않습니다. R² 0.8835를 ‘88.35% 적중률’로 해석하지 않습니다. 세 모델 지표의 평균을 프로그램 전체 정확도라고 표시하지 않습니다. 냉장고는 목표 R² 0.85에 도달하지 않았습니다.

### 5. 예상 전기료 계산 변경

- 이전: 계약 종류·월 누적 사용량을 이용한 주택용 누진 전력량요금 기반의 추가요금 참고 계산.
- 현재: 선택 계획의 예상 kWh에 사용자가 입력한 고정 단가를 곱하는 계산.
- 기본 단가 200원/kWh는 예시이며 공식 한전 요율이 아닙니다.
- 현재 계산은 누진요금·기본요금·세금·할인·TV수신료·청구 반올림을 반영하지 않습니다. 요금 계산이 더 정확해졌다는 의미가 아닙니다.
- 예: TV 100W × 60분 × 2대 = 200Wh = 0.2kWh, 단가 200원/kWh일 때 40원. 다른 가전·누진구간·세금까지 합친 실제 청구액이 아닙니다.

| 기존 `/api/predict`, `/api/recent` | 현재 제공하지 않으며 HTTP 404 |

기존 API를 사용하던 외부 호출자는 새 API로 변경해야 합니다. 웹은 `PREDICTION_API_URL`(기본 내부 주소 `http://127.0.0.1:8000`)로 새 계획 API를 요청합니다. 잘못된 입력은 HTTP 422, 모델/서비스 예외는 503으로 안내합니다. 요청 본문은 1~16,384바이트로 제한합니다.

입력 검사: 가전 1~9종, 중복 채널 금지, 대수 정수 1~50, 시간·시작 지연 0~1,440분, 소비전력 0~20,000W, 가동 비율 0~100%, 단가 0~10,000원/kWh. NaN·무한대·불리언 등 잘못된 숫자 입력과 가전별 미지원 계산 방식을 거부합니다. 세탁 입력 범위와 최근 6개 기록·시각도 검사합니다.

### 7. 제거한 기능과 보존한 자료

- 현재 앱/API에서 집 전체 예측과 기존 환경 기반 예측을 제거했습니다. 새 계획 합계를 집 전체 예측으로 취급하지 않습니다.
- Git에서 `refit_model.joblib`, `refit_sources.json`, `long_history_model.joblib`, `appliance_history_model.joblib` 및 관련 학습/테스트 스크립트를 제거했습니다.
