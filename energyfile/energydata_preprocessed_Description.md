# energydata_preprocessed.csv

## 설명
에너지 사용량 원본 데이터(`energydata_complete.csv`)에 7가지 전처리 정책을 모두 적용한 **전체 데이터셋**입니다.
전체 **19,735행, 32개 컬럼**으로 구성되어 있으며, `2016-01-11 17:00`부터 `2016-05-27 18:00`까지의 10분 간격 시계열 데이터입니다.

## 적용된 전처리 내용
1. 결측치 확인 (결측치 없음, 별도 처리 없음)
2. 노이즈 변수 `rv1`, `rv2` 제거
3. `date` 컬럼에서 `hour`(시간대), `dayofweek`(요일), `is_weekend`(주말 여부) 파생 피처 생성
4. 타깃 변수 `Appliances`의 왜도를 낮추기 위한 `Appliances_log`(log1p 변환값) 컬럼 추가
5. 다중공선성이 높은 실내 온도(T1~T9)를 대표하는 `T_avg_indoor`(실내 평균온도) 파생 컬럼 추가
6. 스케일링은 적용하지 않음 (모델링 단계에서 필요 시 별도 적용)
7. 아직 train/test로 분할하지 않은 전체 데이터

## 용도
데이터 탐색(EDA), 전체 데이터 기준 통계 확인, 모델링 전 최종 점검용으로 사용합니다.
